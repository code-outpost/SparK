# SparK · 数字能源电力测试效率工具箱

> 面向**光伏 / 储能 / 光储一体化**控制器（数采子阵级 · SPPC 站级）测试工程师的一体化**离线**工具箱。
> 计算内核 · 协议速查 · 测试场景模板 · 原理知识库 · 简历与新能源岗位 JD 库 —— 随手即查，**零网络依赖、零后端、零构建**。

SparK 把一名数字能源测试工程师在「求职准备」与「日常测试计算」两条主线上的高频需求，收敛进一个本地单页应用：左侧导航切换模块，右侧即时计算，结果可复制、可导出。所有数据仅存于本机浏览器。

## 1. 特性总览

- **30+ 功能模块**：求职 3 个、测试计算 21 个、场景库 1 个、报告/知识 2 个、系统 2 个、仪表盘 1 个。
- **专业计算内核**：短路电流（序网法）、标幺值折算与参数校验、COMTRADE 波形分析、频率动态与电压无功、对称分量、谐波 THD、短路比、储能配置与分配、一次调频、QU 曲线等。
- **工程速查**：Modbus / IEC 60870-5-104 / SunSpec 协议功能码与寄存器映射；四遥点位自动编排；进制 / IEEE-754 浮点 / 字节序换算。
- **求职加速器**：简历 STAR 化生成、新能源岗位 JD 库（自动提炼协议 / 软件 / 能力要求）、能力雷达图。
- **报告与知识**：测试报告模板自动生成；频率 / 调度 / 通信 / 光储原理与测试方法论卡片。
- **完全离线**：纯静态文件，直接打开即用，无需服务器、无需联网、数据不出本机。
- **可个性化**：9 套背景主题 + 自定义强调色 + 字号调节，设置写入 `localStorage` 持久化。
- **响应式**：桌面侧边栏导航，移动端自动折叠为抽屉式菜单。

## 2. 快速开始

### 方式一：直接打开（最简单）

双击 `index.html`，或在文件管理器中用浏览器打开。

> ⚠️ 部分浏览器对 `file://` 协议下的本地脚本有安全限制。若页面空白或模块不加载，请改用方式二。

### 方式二：本地静态服务器（推荐）

任选一种：

```bash
# Python（自带，无需安装）
python -m http.server 8000
# 然后浏览器访问 http://127.0.0.1:8000

# 或 Node
npx serve .
```

### 浏览器要求

现代 Chromium 内核（Chrome / Edge ≥ 90）或 Firefox ≥ 88。需要支持：

- Canvas 2D（图表绘制）
- ES5+ JavaScript、`localStorage`、`TypedArray` / `DataView`（COMTRADE 二进制解析）
- 移动端响应式布局随屏幕宽度自适应

## 3. 技术架构

## 5. 详细模块说明

### 5.1 求职加速器

#### 简历生成器（`resume`）

- **输入**：基本信息、教育/工作/项目经历、技能标签；支持多套版式（经典 / 瑞士美学 / 时间轴 / 极简 / 西报风 / 创意 / 两栏 / 模块标题背景色等，模板定义于 `jl/templates.js` 与各 `.json`）。
- **算法**：`buildResumeHTML()` 将表单数据渲染为 HTML 简历；STAR 化要点提示引导填写（情境-任务-行动-结果）。
- **输出**：实时预览；可导出 **HTML / JSON（可再编辑）/ PDF**（经 `jl/html2pdf.bundle.min.js`）。移动端另提供 `exportMobile()` 适配导出。
- **持久化**：草稿自动存 `localStorage`，刷新不丢。

#### 岗位JD库（`jd`）

- **功能**：内置 78+ 条新能源（光伏/储能/光储/电力电子/EMS）岗位 JD。
- **算法**：`jdAnalyze()` 按关键词（Modbus / IEC104 / IEC61850 / SunSpec / 数采 / SPPC / MATLAB 等）**自动提炼**岗位所需的「协议 / 软件 / 能力要求」，并按分类 `jdCat()` 筛选、标签 `jdToggle()` 多选。
- **联动**：可一键将某 JD 的能力要求注入「能力雷达图」的目标维度。

#### 能力雷达图（`radar`）

- **输入**：多维度能力自评（0–5 或 0–100），可对比「目标岗位要求」与「当前水平」两组数据。
- **算法**：`drawRadar()`（自研 `CanvasChart.radar`）+ `cmpRadar()` 叠加对比；`saveRadar()` / `rstRadar()` 保存与重置。
- **用途**：面试备战，直观看到能力 Gap。

### 5.2 测试效率计算

#### 光伏计算器（`pv`）

- **输入**：组件开路电压 `Voc`、MPPT 电压上/下限、Voc 温度系数、最低/最高环境温度、负载功率、备电时长、电池电压、系统效率、放电深度 DoD、组件峰值功率 `Wp`。
- **计算**：
  - 极端温度下的组件电压：`V(T) = Voc · [1 + β·(T − 25)]`，校验是否越 MPPT 边界 → 决定**单串组件数**与**每路组串数**。
  - 备电所需容量：`E = P_load · t_backup / (η · DoD · V_bat)`。
  - 温度降额后的可用功率。

#### 一次调频（`pf`）

- **输入**：实际频率 `f`、额定频率 `fn`、动作死区 `fd`、基准功率 `Pn`、调频公式模板（下拉）或自定义 JavaScript 表达式。
- **算法**：标准一次调频下垂 `ΔP = Pn · k · (fn − f)`，当 `|fn − f| < fd` 时输出 0（死区）。支持用户以 JS 表达式自定义（如含限幅、分段斜率）。
- **联动**：与「公式速算 `lab`」中的一次调频下垂计算同源。

#### QU曲线（`qu`）

- **输入**：斜率 `k (kV/MVar)`、电压目标值 `Ucons`、电压实时值 `Ureal`。
- **算法**：按电压偏差 `ΔU = Ureal − Ucons` 与斜率 `k` 计算所需调节无功 `Q = ΔU / k`，用于无功电压控制（AVC）的整定校核。

#### 储能分配（`sa`）

- **输入**：总目标功率 `P_total`、充电截至 SOC、放电截至 SOC。
- **算法**：在多储能单元间按 SOC 均衡策略分配功率（`saStrat()`），高 SOC 单元多放电、低 SOC 少放电，输出各单元功率指令。

#### 储能配置（`ess`）

- **输入**：功率 `P`、放电时长、日峰谷转移功率差、每日放电时长、每日/年循环次数、单位投资成本、运维成本、项目年限、储能容量 `E`。
- **算法**：容量配置建议 + 经济性指标（单位储能成本、年收益、投资回收期、LCOE 近似）。

#### 功率计算（`pc`）

- **输入（两种模式，`pcTab()` 切换）**：
  - 模式 A：电压 `U`、电流 `I`、电压相位角 `θu`、电流相位角 `θi` → 有功 `P=U·I·cos(θu−θi)`、无功 `Q=U·I·sin(θu−θi)`、视在 `S=U·I`、功率因数 `PF=cos(θu−θi)`。
  - 模式 B：已知 `U`、`I`、`PF`、`S` 等部分量互推其余量。
- **支持**：单相与三相（线/相）换算。

#### 功率因数（`pfc`）

- **输入**：有功 `P`、无功 `Q`、视在 `S`、功率因数 `PF`。
- **算法**：`S=√(P²+Q²)`、`PF=P/S`、所需补偿电容 `Qc = P·(tanφ1 − tanφ2)`（目标 PF 提升后的补偿量）。

#### 站级SOC（`soc`）

- **输入**：多 PCS 的额定容量、当前 SOC、功率指令。
- **算法**：站级 SOC 加权统计、各单元 SOC 均衡度评估，辅助站级能量管理策略验证。

#### 对称分量（`sym`）

- **输入**：三相电压（或电流）`Va/Vb/Vc` 及其相位角 `θa/θb/θc`。

- **算法**：对称分量变换

  ```
  [V0]            [1   1    1 ] [Va]
  [V1] = 1/3 ·    [1   a    a²] [Vb]
  [V2]            [1   a²   a ] [Vc]      a = e^(j120°)
  ```

  输出正序 `V1`、负序 `V2`、零序 `V0` 及**三相不平衡度** `ε = V2/V1`（或含 V0 的 IEC 推荐式）。

#### THD谐波（`thd`）

- **输入**：谐波幅值序列（逗号分隔，**第 1 个为基波**）、单位。
- **算法**：`THD = √(Σ h=2..n Vh²) / V1`，判定是否越 GB/T 14549 / IEEE 519 限值。

#### 短路比（`scr`）

- **输入**：短路容量 `Ssc`、短路电流 `Isc`、系统电压 `Un`、设备额定容量 `Pn`。
- **算法**：`Ssc = √3·Un·Isc`；短路比 `SCR = Ssc / Pn`，用于评估并网薄弱程度与设备耐受能力。

#### 短路电流（`fault`）★新增

- **输入**：
  - 系统参数：系统电压 `U`、短路容量 `Ssc`、系统 `X/R`、线路长度、正序 `R1/X1`、零序 `R0/X0`（Ω/km）、过渡电阻 `Rf`、断路器开断能力。
  - 双电源（可选）：右侧短路容量 `Ssc'`、右侧 `X/R'`。
  - 故障类型：三相 / 单相接地 / 两相 / 两相接地。
  - 中性点：直接接地 / 消弧线圈（`Xn`）/ 接地电阻（`Rn`）。
- **算法（序网法）**：
  - 系统阻抗 `Zs = U²/Ssc`，按 `X/R` 拆分为 `R、X`：`R = |Z|/√(1+(X/R)²)`，`X = R·(X/R)`。
  - 正/负序 `Z1=Z2=Zs+（线路序阻·长度）`；零序 `Z0=Zs+R0·L+3·Zn`（含中性点补偿）。
  - 边界条件求故障点电流，再经 `fromSeq` 合成三相电流。
  - **直流时间常数** `τ = X_eq / (2π·50·R_eq)`，用于校验断路器开断直流分量能力。
  - **断路器校核**：`Imax = max(|Ia|,|Ib|,|Ic|)` 与额定开断电流比对，输出合格/越限徽标。
- **参考**：开源 [`power_tool/faults.py`](https://github.com/zoudehupowersystem/power_tool) 序网计算逻辑。

#### 标幺值（`pu`）★新增

- **输入**：
  - 基准：基准电压 `Ubase`、基准容量 `Sbase`。
  - 线路：序阻 `R1/X1`、对地电容 `C1`、长度 → 折算标幺阻抗、电纳、自然阻抗 `Zc`。
  - 双绕组变压器：短路损耗 `Pk`、阻抗 `Uk%`、空载损耗 `P0`、空载电流 `I0%`、额定 `SN/UN`。
  - 三绕组变压器：`Pk_HM/Pk_HL/Pk_ML`、`Uk_HM%/Uk_HL%/Uk_ML%`、各侧容量与电压。
- **算法**：
  - 基准阻抗 `Zbase = Ub²/Sb`、基准导纳 `Ybase = 1/Zbase`。
  - 线路标幺：`Rpu=R·L/Zbase` 等；线路波阻抗 `Zc=√(X/B)`。
  - 双绕组：`Rk = Pk·Ub²/(1000·SN²)`、`Xk = (Uk%·Ub²)/(100·SN)`（标幺）。
  - **三绕组 T 型分解**：`Pk_H=(Pk_HM+Pk_HL−Pk_ML)/2` 等，再分别折算各绕组电阻/电抗。
  - **参数校验**（`puWarn()`）：对照典型范围（如 `Uk%`、空载电流、X/R）给出超限告警徽标。
- **参考**：开源 `power_tool/params.py` 的标幺折算与典型参数校验。

#### 波形分析 · COMTRADE（`comtrade`）★新增

- **输入**：`.cfg` 配置文件 + `.dat` 数据文件（文件选择框），分析通道（逗号分隔序号，从 1 起），窗口起点（ms）。
- **解析**：
  - `ctParseCfg()`：解析 CFG 头部（采样率、通道定义、数据类型、时间标记）。
  - `ctParseDat()`：支持 **ASCII / BINARY16（Int16-LE）/ BINARY32（Int32-LE）** 三种格式，按因子 `a`、`b` 还原工程值。
- **分析（`ctAnalyze()`）**：
  - 滑窗 **DFT**（`ctDft()`）提取工频相量（幅值、相角）。
  - 基波 RMS、1–10 次谐波幅值与含量。
  - **序分量**：正序/负序/零序 + 三相不平衡度 `ε`。
  - **THD** 总谐波畸变率。
  - 波形曲线绘制于 `ct-wave` 画布。
- **参考**：开源 `power_tool/comtrade.py` 的录波解析与特征提取。

#### 频率动态（`fdyn`）★新增

- **输入**：
  - 频率动态：系统容量 `S`、惯量 `H`、负载阻尼 `D`、功率缺额 `ΔP`、调差率 `R`、调速器时间常数 `Tg`、额定频率 `f0`、仿真时长。
  - 电压无功：送/受端电压 `Vs/Vr`、线路电抗 `X`、电阻 `R`、负荷有功 `P`、无功 `Q`、波阻抗 `Zc`、额定 `U`。
- **算法**：
  - **摆动方程**（欧拉积分，`dt=0.05s`）：
    `2H·dΔf/dt = (−ΔP + P_gov − D·Δf)·f0/S`
    调速器一阶响应 `P_gov` 按调差率 `R` 与 `Tg` 动态恢复。
  - 输出：初始 **ROCOF**（`df/dt` 起点）、频率**最低点（nadir）**及到达时刻、稳态频降。
  - **电压无功**：自然功率 `Pnat = U²/Zc`、电压降落 `ΔV = (P·R+Q·X)/Vs`、最大传输功率、为维持受端电压所需无功。
  - 频率曲线由新增 `CanvasChart.line` 绘制。
- **参考**：开源 `power_tool` 的频率/功角动态思路。

#### 四遥点位（`siyao`）

- **输入**：遥信 YX / 遥测 YC / 遥控 YK / 遥调 YT 起始地址，相对位置，序号（单个如 `5`，或范围如 `1-20`）。
- **算法**：`calcSiYao()` / `calcYc()` 按 IEC 60870-5-104 / Modbus 点表规则，自动编排连续点位地址与描述，`rstSiyao()` 重置。

#### 进制转换（`base`）

- **输入**：数值、输入进制（2/8/10/16）。
- **算法**：`convBase()` 在任意进制间互转，支持大整数。

#### 浮点精度（`float`）

- **输入**：十进制浮点数；或 32 位 / 64 位十六进制（含字节序选择：大端/小端）。
- **算法**：`float32()` / `float64()` 与 `hex2f32()` / `hex2f64()` 实现十进制 ↔ IEEE-754（单/双精度）互转，可视化符号位/阶码/尾数拆解。

#### 通信速查（`comm`）

- **输入**：功能码、PLC 地址（如 `40001`）、原始值 `raw`、比例系数 `k`、偏移 `b`、单位。
- **算法**：Modbus 地址区换算（4x/3x/0x/1x）、`value = raw·k + b` 工程量还原，给出功能码含义说明。

#### 公式速算（`lab`）

- **功能**：把知识库核心公式做成可交互计算器，含一次调频下垂 `ΔP`、ACE 区域控制偏差、阻尼比 `ζ`、虚拟惯量支撑功率、QU 无功等，输入参数即时出结果，验证对公式的理解。标签页 `labTabs` 由 JS 动态渲染。

#### 协议速查（`proto`）

- **功能**：Modbus / IEC 60870-5-104 / SunSpec 功能码、寄存器映射、帧结构速查卡片，调试通信时随手查阅。

### 5.3 测试场景库

#### SPPC/数采场景（`scenario`）

- **内置场景**：纯光 / 纯储 / 光储 / 工商业等 SPPC（站级）与数采（子阵级）预设场景。
- **结构**：每个场景含「前置条件 → 测试步骤 → 预期结果 → 记录表」。
- **导出**：`exportScenario()` 勾选所需场景，一键生成可执行的测试清单（可复制 / 打印）。

### 5.4 报告与知识

#### 报告模板（`report`）

- **输入**：项目名称、测试对象、测试人员、测试日期、设备型号、软件版本。
- **算法**：`genReport()` 套用模板，结合场景库与计算结果为骨架，生成结构化测试报告草稿，便于补充与归档。

#### 知识库（`knowledge`）

- **内容**：原理 + 公式 + 测试要点卡片，覆盖**频率 / 调度 / 通信 / 光储**四大主题（`kbCat()` 分类筛选）。
- **用途**：测试前温习原理、测试后对照要点，沉淀团队经验。

### 5.5 系统

#### 设置（`set`）

- 主题颜色（强调色 swatches + 取色器）、背景主题（9 套）、字号滑杆、恢复默认。
- 所有设置经 `loadSettings()` / 即时写入 `localStorage`，下次打开仍生效。

#### 关于（`about`）

- 工具定位、四大能力（求职 / 算 / 景 / 知）简介与模块清单。

## 10. 技术说明与待优化

- **`three.min.js` 为死重**：目前 3D 相关入口（`initIntro3D`）为空实现、首页 hero 使用 Canvas 2D，故 `three.min.js`（约 600 KB）加载但**未使用**，后续可移除以加快首屏。
- **单文件巨 IIFE**：`app.js` 为单一 IIFE，模块间通过 `window.` 暴露函数。功能继续增长后，建议按模块拆分或引入轻量构建，以改善可维护性。
- **自定义图表引擎**：`CanvasChart` 为自研 Canvas 2D 引擎，已支持 `bar/hBar/quLine/pfCurve/radar/line`；新增图表类型时建议复用现有图元而非内联绘制。
- **COMTRADE 二进制**：当前支持 BINARY16/BINARY32 小端（Intel 字节序），大端格式可按需扩展。
- **安全提示**：部分模块（如「一次调频」自定义公式）使用 `new Function` 执行用户表达式，仅限**本地可信环境**使用；若部署到公网需先做沙箱/白名单处理。
