# SparK · 数字能源测试效率工具箱

> 面向**光伏 / 储能 / 光储一体化**控制器（数采子阵级 · SPPC 站级）测试工程师的一体化**离线**工具箱。
> 专业计算内核 · GOOSE / MMS / Modbus 报文解析 · 调频与稳定控制校核 · 指令下发 · 原理知识库 · 简历与新能源岗位 JD 库 —— 随手即查，**零网络依赖、零后端、零构建**。

SparK 把一名数字能源测试工程师在「求职准备」与「日常测试计算」两条主线上的高频需求，收敛进一个本地单页应用：左侧导航切换模块，右侧即时计算，结果可复制、可导出。所有数据仅存于本机浏览器。

- **43 个导航模块**：仪表盘 1、求职 3、频率与稳定控制 8、光伏与储能 9、电能质量与电网计算 10、通信与协议 6、基础工具 4、系统 2，按 5 大语义分组组织。

- **调频与稳定控制套件**：一次调频校验（新能源 GB/T 19963.1-2021 / 同步机 DL/T 1870-2018 两套判据）、二次调频 AGC（ACE / 变化率限值 / 投运率）、虚拟惯量、POD 阻尼整定，均含**计算原理 + 参考资料 + 学习教程 + 波形参考**。
- **协议报文解析**：GOOSE 报文解析与 CID 生成（IEC 61850-8-1 / 61850-6）、IEC 61850 MMS/ACSE 报文查看（BER 浅解析）、Modbus RTU CRC 校验与帧构造。
- **指令下发助手**：Modbus TCP 组帧（MBAP+PDU，功能码 03/06/10/05）+ 调度命令模板（AGC 有功 / AVC 无功 / AVC 电压 / 启停机 / 限幅 / 模式切换），生成下发帧与回读校验帧。
- **工程速查**：四遥点位自动编排；进制 / IEEE-754 浮点 / 字节序 / 位运算（寄存器寻址式）换算。
- **求职加速器**：简历 STAR 化生成、新能源岗位 JD 库（自动提炼协议 / 软件 / 能力要求）、能力雷达图。
- **背景音乐**：设置页可开启随机播放在线歌曲，作为页面背景音乐（底部常驻播放条，跨工具页不中断）。
- **完全离线**：纯静态文件，直接打开即用，无需服务器、无需联网、数据不出本机。
- **可个性化**：9 套背景主题 + 自定义强调色 + 字号调节 + 实时天气，设置写入 `localStorage` 持久化。
- **响应式**：桌面侧边栏导航，移动端自动折叠为抽屉式菜单。

## 2. 快速开始

### 方式一：直接打开（最简单）
双击 `index.html`，或在文件管理器中用浏览器打开。
> ⚠️ 部分浏览器对 `file://` 协议下的本地脚本有安全限制。若页面空白或模块不加载，请改用方式二。

### 方式二：本地静态服务器（推荐）
任选一种：

```bash
# Python（自带，无需安装）
python -m http.server 8000
# 然后浏览器访问 http://127.0.0.1:8000

# 或 Node
npx serve .
```

### 浏览器要求
现代 Chromium 内核（Chrome / Edge ≥ 90）或 Firefox ≥ 88。需要支持：
- Canvas 2D（图表绘制）
- ES5+ JavaScript、`localStorage`、`TypedArray` / `DataView`（COMTRADE 二进制解析）
- HTML5 `<audio>`（背景音乐）
- 移动端响应式布局随屏幕宽度自适应

> 背景音乐依赖在线音频直链；首次播放需用户点击（浏览器自动播放策略）。

## 3. 技术架构

| 维度 | 说明 |
|---|---|
| **形态** | 单页应用（SPA），纯前端，**无框架、无打包器、无依赖安装** |
| **语言** | HTML5 + CSS3 + 原生 JavaScript（`app.js` 主逻辑 IIFE，各功能模块独立 `*.js` IIFE 挂 `window.xxx`） |
| **样式** | 内置 CSS（深色科技风，`index.html` `<style>` 块），CSS 变量驱动主题 |
| **图表** | 自研 `CanvasChart` 引擎（Canvas 2D），支持 `bar / hBar / quLine / pfCurve / radar / line` 六种图元；波形统一由 `wave.js` 的 `drawWave()` 绘制 |
| **状态** | 用户设置、歌单、简历草稿存 `localStorage`；计算为无状态即时运算 |
| **依赖** | `jl/templates.js`（简历模板）、`jl/html2pdf.bundle.min.js`（PDF 导出）；**`three.min.js` 已于 2026-08-28 删除**（详见 §10） |
| **文件规模** | `index.html` ≈ 3290 行，`app.js` ≈ 5290 行，外加 23 个独立功能模块 `*.js`（各 47–1050 行不等） |

**模块切换机制**：每个模块是 `index.html` 中一个 `<div class="sect" id="s-<id>">`；点击左侧导航调用 `nav(el, '<id>')`，给目标 section 加 `.on`（显示）并移除其它，纯 DOM 显隐，无路由。导航项按 5 大语义分组组织，默认折叠、点击展开（`navgroup.js`）。

**安全**：「一次调频」等模块的自定义公式，早期用 `new Function` 执行用户表达式，存在 XSS 风险；现已替换为自研**递归下降解析器**（`tokenizeExpr` + `evalFormula`），仅本地可信环境使用亦安全。

## 5. 详细模块说明

> 计算类模块普遍提供「计算工具 + 计算原理 + 参考资料（材料支持）+ 学习教程 + 使用说明」卡片。有明确标准的直接引标准号与条款；属于工程惯例或设备规格值的会显式标注「非国标强制，以 XX 为准」，不把惯例冒充标准。

### 5.1 仪表盘与求职加速器

#### 仪表盘（`home`）
首页：常用公式速算亮点、模块入口导航、使用统计。

#### 简历生成器（`resume`）
- **输入**：基本信息、教育/工作/项目经历、技能标签；支持多套版式（经典 / 瑞士美学 / 时间轴 / 极简 / 西报风 / 创意 / 两栏 / 模块标题背景色等，模板定义于 `jl/templates.js` 与各 `.json`）。
- **算法**：`buildResumeHTML()` 将表单数据渲染为 HTML 简历；STAR 化要点提示引导填写（情境-任务-行动-结果）。
- **输出**：实时预览；可导出 **HTML / JSON（可再编辑）/ PDF**（经 `jl/html2pdf.bundle.min.js`）。移动端另提供 `exportMobile()` 适配导出。
- **持久化**：草稿自动存 `localStorage`，刷新不丢。

#### 岗位JD库（`jd`）
- **功能**：内置 78+ 条新能源（光伏/储能/光储/电力电子/EMS）岗位 JD。
- **算法**：`jdAnalyze()` 按关键词（Modbus / IEC104 / IEC61850 / SunSpec / 数采 / SPPC / MATLAB 等）**自动提炼**岗位所需的「协议 / 软件 / 能力要求」，并按分类 `jdCat()` 筛选、标签 `jdToggle()` 多选。
- **联动**：可一键将某 JD 的能力要求注入「能力雷达图」的目标维度。

#### 能力雷达图（`radar`）
- **输入**：多维度能力自评（0–5 或 0–100），可对比「目标岗位要求」与「当前水平」两组数据。
- **算法**：`drawRadar()`（自研 `CanvasChart.radar`）+ `cmpRadar()` 叠加对比；`saveRadar()` / `rstRadar()` 保存与重置。
- **用途**：面试备战，直观看到能力 Gap。

### 5.2 频率与稳定控制

#### 一次调频（`pf`）
- **输入**：实际频率 `f`、额定频率 `fn`、动作死区 `fd`、基准功率 `Pn`、调频公式模板（下拉）或自定义表达式。
- **算法**：标准一次调频下垂 `ΔP = Pn · k · (fn − f)`，当 `|fn − f| < fd` 时输出 0（死区）。支持用户以表达式自定义（含限幅、分段斜率）。
- **联动**：与「公式速算 `lab`」中的一次调频下垂计算同源。

#### 调频校验（`pfr`）★标准校验
- **输入**：额定频率 `fN`、频率偏差 `Δf`、测试功率 `Pt`、调差率 `σ%`、死区、限幅、响应时间要求。
- **算法**：`ΔPt = −Kf·(Δf/fN)·Pt`，其中 `Kf = 100/σ%`。判据分两套：
  - **新能源**：GB/T 19963.1-2021 5.3（死区 ±0.03~0.1 Hz、Kf 10~50、限幅增≥6%/减≥10% **Pt**、滞后≤2 s / 上升≤9 s / 调节≤15 s / 偏差≤±1% PN）。
  - **同步机**：DL/T 1870-2018 附录 A（火电电液 ±0.033 Hz、水电 ±0.05 Hz、核电≤0.08 Hz；调差率火电/燃机/核电 4~5%、水电≤3%；限幅按 **PN**）。
- **关键坑**：新能源限幅按 `Pt`、同步机按 `PN`，基准不同。附计算原理与频率响应波形。

#### 二次调频（`agc`）★标准校验
- **输入**：联络线功率偏差 `ΔPtie`、频率偏差 `Δf`、频率偏差系数 `B`、变化率限值相关参数。
- **算法**：
  - `ACE = ΔPtie + B·Δf`（TBC / FFC / FTC 三模式）。
  - 变化率限值 GB/T 19963.1 表 1（`Pn<30 MW → 3/10 MW`；`30~150 MW → Pn/10、Pn/3`；`>150 MW → 15/50 MW`）。
  - 投运率 = 闭环时间 / 运行时间（全月 <99.9% 考核）；指令合格率 ≥98%（按日统计、1 min 均值）。
- **注意**：`B` 的符号与单位（MW/Hz vs MW/0.1 Hz）各调度机构约定不同，以本地定值单为准。

#### 虚拟惯量（`vi`）★标准校验
- **输入**：惯量时间常数 `TJ`（= 2H）、额定频率 `fN`、频率变化率 `df/dt`、测试功率 `Pt`、死区。
- **算法**：`ΔPt = −(TJ/fN)·(df/dt)·Pt`；ROCOF 窗口 100~200 ms；触发需 `|Δf|>死区` 且 `Pt>20%PN` 且 `Δf·df/dt>0`（方向一致才动作）；上升≤1 s、偏差≤±1% PN。
- **算例**：`TJ=10 / fN=50 / df/dt=−0.5 / Pt=200` → **+20 MW**（与 GB/T 19963.1 工程算例一致）。附 ROCOF 波形。

#### POD阻尼（`pod`）★整定
- **输入**：振荡衰减包络（逐波峰幅值）、目标阻尼比、本地/区间振荡频率。
- **算法**：阻尼比反推 `δ = (1/n)·ln(A₁/Aₙ₊₁)`、`ζ = δ/√(4π²+δ²)`；lead-lag 整定 `α = (1+sinφ)/(1−sinφ)`、`T1 = √α/ω`、`T2 = 1/(ω·√α)`；本地模式 0.8~2.0 Hz / 区间模式 0.1~0.8 Hz。
- **关键提示**：阻尼比 3%/5% 门槛属**工程惯例、非国标强制数值**，以所在电网稳定计算规范为准。附阻尼振荡波形。

#### 频率动态（`fdyn`）
- **输入**：系统容量 `S`、惯量 `H`、负载阻尼 `D`、功率缺额 `ΔP`、调差率 `R`、调速器时间常数 `Tg`、额定频率 `f0`、仿真时长；电压无功：送/受端电压、线路 `X/R`、负荷 `P/Q`、波阻抗 `Zc`、额定 `U`。
- **算法**：摆动方程欧拉积分（`dt=0.05 s`）：`2H·dΔf/dt = (−ΔP + P_gov − D·Δf)·f0/S`，调速器按 `R`、`Tg` 动态恢复；输出初始 ROCOF、频率最低点（nadir）及到达时刻、稳态频降；电压无功含自然功率、电压降落、最大传输功率。频率曲线由 `CanvasChart.line` 绘制。

#### QU曲线（`qu`）
- **输入**：斜率 `k (kV/MVar)`、电压目标值 `Ucons`、电压实时值 `Ureal`。
- **算法**：`ΔU = Ureal − Ucons`，`Q = ΔU / k`，用于无功电压控制（AVC）整定校核。

#### SVG无功（`svgctrl`）
- **输入**：无功 `Q`、电压 `U`、额定容量 `S`、Q/U 下垂系数或 PF 控制目标。
- **算法**：Q/U 下垂与 PF 控制两种模式，判断运行点是否越限；容量包络 `√(S²−P²)`。SVG 电流源型特性、与 SVC/并联电容对比、Qc = P(tanφ₁−tanφ₂)。
- **注意**：SVG 响应时间（常见 ≤30 ms，高性能 ≤5~10 ms）属**设备技术规格值、非国标强制**，以设备技术规范书为准。

### 5.3 光伏与储能

#### 光伏计算器（`pv`）
- **输入**：组件开路电压 `Voc`、MPPT 电压上/下限、Voc 温度系数、最低/最高环境温度、负载功率、备电时长、电池电压、系统效率、放电深度 DoD、组件峰值功率 `Wp`。
- **计算**：极端温度下的组件电压 `V(T) = Voc·[1 + β·(T − 25)]` 校验是否越 MPPT 边界 → 决定单串组件数与每路组串数；备电容量 `E = P_load·t_backup / (η·DoD·V_bat)`；温度降额后可用功率。

#### PV失配（`pvm`）
- **输入**：各组串 `Voc / Isc / Pmax`。
- **算法**：电流/电压失配率与功率损失估算（区别于「光伏计算器」`pv`，本模块专注失配损耗）。

#### 站级SOC（`soc`）
- **输入**：多 PCS 额定容量、当前 SOC、功率指令。
- **算法**：站级 SOC 加权统计、各单元 SOC 均衡度评估，辅助站级能量管理策略验证。

#### 储能分配（`sa`）
- **输入**：总目标功率 `P_total`、充电截至 SOC、放电截至 SOC。
- **算法**：多储能单元间按 SOC 均衡策略分配功率（`saStrat()`），高 SOC 单元多放电、低 SOC 少放电，输出各单元功率指令。

#### 储能配置（`ess`）
- **输入**：功率 `P`、放电时长、日峰谷转移功率差、每日放电时长、每日/年循环次数、单位投资成本、运维成本、项目年限、储能容量 `E`。
- **算法**：容量配置建议 + 经济性指标（单位储能成本、年收益、投资回收期、LCOE 近似）。

#### 电池均衡（`bat`）
- **输入**：各电池簇 SOC 列表、充放电参数。
- **算法**：SOC 极差/标准差/均衡策略评估；充放电库仑效率与往返能量效率。

#### PCS效率（`pcs`）
- **输入**：额定功率、负载率-效率点序列。
- **算法**：最高效率点、平均效率、近似 CEC 加权效率（CEC 权重属工程近似）。

#### 绝缘阻抗（`ins`）
- **输入**：正负极对地电压（不平衡桥法）或直接输入 `R+ / R-`。
- **算法**：估算等效绝缘电阻，给出 **≥1 MΩ/V** 判据（依据 IEC 62446）。

#### 出力制御(日)（`jpoc`）★日本遠隔出力制御
- **输入**：接続申込日 / 認定出力 / 抑制上限% / 自家消費分 / 年度累计。
- **算法**：ルール判定（旧 30 日 / 新 360 時間(太陽光)・720 時間(風力) / 無制限・無補償 / 指定ルール；10 kW 未満当面対象外）；抑制電力 = 認定出力 × (1 − 出力上限%)；抑制電量 / 余剰買取損失试算。
- **关键坑**：30 日ルール按「日数」、360/720 時間ルール按「累計時間」管理，单位不同。依拠：METI 資源エネルギー庁、九州電力送配電「出力制御機能付 PCS 等技術仕様書」(2023-06-30 改定)、東京電力 PG、四国電力。

### 5.4 电能质量与电网计算

#### 功率计算（`pc`）
- **输入（两种模式，`pcTab()` 切换）**：
  - 模式 A：电压 `U`、电流 `I`、电压相位角 `θu`、电流相位角 `θi` → `P=U·I·cos(θu−θi)`、`Q=U·I·sin(θu−θi)`、`S=U·I`、`PF=cos(θu−θi)`。
  - 模式 B：已知 `U`、`I`、`PF`、`S` 等部分量互推其余量。
- **支持**：单相与三相（线/相）换算。

#### 功率因数（`pfc`）
- **输入**：有功 `P`、无功 `Q`、视在 `S`、功率因数 `PF`。
- **算法**：`S=√(P²+Q²)`、`PF=P/S`、所需补偿电容 `Qc = P·(tanφ1 − tanφ2)`。

#### 无功补偿（`pfcomp`）
- **输入**：有功 `P`、当前 `PF`、目标 `PF`。
- **算法**：补偿容量 `Qc`、补偿后 `S`、电流下降百分比，给出 SVG/逆变器容量建议（区别于 `pfc` 原计算器）。

#### 三相不平衡（`unb`）
- **输入**：三相电压（或电流）幅值与相角。
- **算法**：对称分量法求正/负序与不平衡度%，对照 **2% 阈值**判合格（并网/电能质量必查，依据 GB/T 15543）。

#### 谐波THD（`harm`）
- **输入**：2~31 次谐波含有率 + 基波有效值。
- **算法**：THD-F / THD-R、单次谐波排序、近似 THF，附 GB/T 14549 / IEEE 519 参考。

#### THD谐波（`thd`）
- **输入**：谐波幅值序列（逗号分隔，**第 1 个为基波**）、单位。
- **算法**：`THD = √(Σ h=2..n Vh²) / V1`，判定是否越 GB/T 14549 / IEEE 519 限值。

#### 对称分量（`sym`）
- **输入**：三相电压（或电流）`Va/Vb/Vc` 及其相位角 `θa/θb/θc`。
- **算法**：对称分量变换
  ```
  [V0]            [1   1    1 ] [Va]
  [V1] = 1/3 ·    [1   a    a²] [Vb]
  [V2]            [1   a²   a ] [Vc]      a = e^(j120°)
  ```
  输出正序 `V1`、负序 `V2`、零序 `V0` 及**三相不平衡度** `ε = V2/V1`（或含 V0 的 IEC 推荐式）。

#### 短路比（`scr`）
- **输入**：短路容量 `Ssc`、短路电流 `Isc`、系统电压 `Un`、设备额定容量 `Pn`。
- **算法**：`Ssc = √3·Un·Isc`；短路比 `SCR = Ssc / Pn`，用于评估并网薄弱程度与设备耐受能力。

#### 短路电流（`fault`）
- **输入**：系统电压 `U`、短路容量 `Ssc`、系统 `X/R`、线路长度、正序 `R1/X1`、零序 `R0/X0`、过渡电阻 `Rf`、断路器开断能力；可选双电源、中性点（直接接地/消弧线圈/接地电阻）、故障类型（三相/单相接地/两相/两相接地）。
- **算法（序网法）**：系统阻抗 `Zs = U²/Ssc`，按 `X/R` 拆分 `R、X`；正/负序 `Z1=Z2=Zs+线路序阻·长度`；零序 `Z0=Zs+R0·L+3·Zn`；边界条件求故障点电流后合成三相；直流时间常数 `τ = X_eq / (2π·50·R_eq)`；断路器校核 `Imax` 与额定开断电流比对。

#### 标幺值（`pu`）
- **输入**：基准 `Ubase/Sbase`；线路序阻/对地电容/长度；双/三绕组变压器短路损耗 `Pk`、阻抗 `Uk%`、空载损耗 `P0`、空载电流 `I0%`、额定 `SN/UN`。
- **算法**：基准阻抗 `Zbase = Ub²/Sb`；线路标幺折算、波阻抗 `Zc`；双绕组 `Rk/Pk` 折算；三绕组 T 型分解与参数校验（`puWarn()` 对照典型范围告警）。
- **参考**：开源 `power_tool/params.py` 的标幺折算与典型参数校验。

### 5.5 通信与协议

#### GOOSE报文解析（`goose`）
- **输入**：GOOSE 报文十六进制或 PCAP 抓包；可选 SCD/ICD/CID 做语义解读。
- **功能（三 Tab）**：
  - **解析报文**：解码数据集（BOOL/INT/BIT 等）、测试计数、状态号、时标；SCD/ICD/CID 语义对照。
  - **生成 CID**：表单填控制块/通信参数 + 动态 FCDA 条目表 → 生成 IEC 61850-6 CID XML（可「从已解析报文预填」、「生成 GOOSE 示例报文」回灌）。
  - **使用说明**：UDM 收发 / PMA(IEC104) 协议级通用方法论。
- **协议**：IEC 61850-8-1 GOOSE。

#### MMS报文（`mms`）
- **输入**：IEC 61850 MMS / ACSE 报文（十六进制）。
- **算法**：BER 浅层解析，识别 initiate / confirmed / AARQ / AARE，附 ACSI 映射提示。

#### Modbus CRC（`modbus`）
- **输入**：RTU 帧（十六进制）或构造参数（从站地址、功能码、寄存器地址、值）。
- **算法**：CRC16（多项式 0xA001）校验 / 构造请求帧 / 解析 0x01/0x02/0x03/0x04 响应与异常码（依据 Modbus V1.02）。

#### 四遥点位（`siyao`）
- **输入**：遥信 YX / 遥测 YC / 遥控 YK / 遥调 YT 起始地址，相对位置，序号（单个如 `5`，或范围如 `1-20`）。
- **算法**：`calcSiYao()` / `calcYc()` 按 IEC 60870-5-104 / Modbus 点表规则自动编排连续点位地址与描述，`rstSiyao()` 重置。

#### 通信速查（`comm`）
- **输入**：功能码、PLC 地址（如 `40001`）、原始值 `raw`、比例系数 `k`、偏移 `b`、单位。
- **算法**：Modbus 地址区换算（4x/3x/0x/1x）、`value = raw·k + b` 工程量还原，给出功能码含义说明。

#### 波形分析 · COMTRADE（`comtrade`）
- **输入**：`.cfg` 配置文件 + `.dat` 数据文件，分析通道（逗号分隔序号，从 1 起），窗口起点（ms）。
- **解析**：`ctParseCfg()` 解析头部；`ctParseDat()` 支持 ASCII / BINARY16（Int16-LE）/ BINARY32（Int32-LE）按因子 `a`、`b` 还原工程值。
- **分析（`ctAnalyze()`）**：滑窗 DFT（`ctDft()`）提取工频相量；基波 RMS、1–10 次谐波；序分量与不平衡度；THD；波形绘于 `ct-wave`。
- **参考**：开源 `power_tool/comtrade.py`。

### 5.6 基础工具

#### 进制转换（`base`）
- **输入**：数值、输入进制（2/8/10/16）。
- **算法**：`convBase()` 在任意进制间互转，支持大整数。

#### 浮点精度（`float`）
- **输入**：十进制浮点数；或 32 位 / 64 位十六进制（含字节序选择：大端/小端）。
- **算法**：`float32()` / `float64()` 与 `hex2f32()` / `hex2f64()` 实现十进制 ↔ IEEE-754（单/双精度）互转，可视化符号位/阶码/尾数拆解。

#### 位运算（`bit`）
- **输入**：寄存器标签（地址）、寄存器个数（1/2）、值类型（UINT16/INT16/UINT32/INT32/FLOAT32/位域）、字序（BE/LE、ABCD/CDAB/BADC/DCBA）。
- **算法**：寄存器寻址式位域解析；横向位图（bit0 在左、从小到大排列、可点击翻转）；BIT 起始~结束字段提取（掩码/有符号值）；单 BIT 置1/清0/翻转；保留 IEC 61850 品质位解码预设；IEEE-754 / 字节序可视化。

#### 公式速算（`lab`）
- **功能**：把核心公式做成可交互计算器，含一次调频下垂 `ΔP`、ACE 区域控制偏差、阻尼比 `ζ`、虚拟惯量支撑功率、QU 无功等，输入参数即时出结果，验证对公式的理解。标签页 `labTabs` 由 JS 动态渲染。

## 10. 技术说明与待优化

- **`three.min.js` 已删除**：早期随包但未使用的 3D 库（约 600 KB）已于 2026-08-28 移除，首屏更轻。
- **安全解析器替换 `new Function`**：原「一次调频」自定义公式用 `new Function` 执行用户表达式（公网部署有 XSS 风险），现已改为自研**递归下降解析器**（`tokenizeExpr` + `evalFormula`），支持 `+−*/%^`、比较、逻辑、三元、括号与 `abs/min/max/sqrt/pow` 等函数，注入样本均被拦截。
- **图表引擎 resize 修复**：`CanvasChart` 各实例原各自挂 `window.resize` 且闭包捕获旧尺寸，缩放后绘制错误；已统一为全局登记表 + 单个防抖监听 + `ResizeObserver` 思路，隐藏图表跳过重绘，监听数大幅下降。
- **自定义图表引擎**：`CanvasChart` 支持 `bar/hBar/quLine/pfCurve/radar/line`；波形统一走 `wave.js` 的 `drawWave()`。
- **单一主 IIFE 渐拆分为模块文件**：`app.js` 仍为主逻辑，但功能模块已拆分为 23 个独立 `*.js`（IIFE 挂 `window.xxx`）。功能继续增长后，建议按领域进一步归并或引入轻量构建。
- **COMTRADE 二进制**：当前支持 BINARY16/BINARY32 小端（Intel 字节序），大端格式可按需扩展。
- **已移除导航的模块**：`proto / scenario / report / knowledge` 代码保留但不再可达（见 §5.8），如需恢复可重新挂入导航分组。
- **安全提示**：背景音乐仅做本地播放，不抓取/转码任何音频，也不内置受版权保护的曲库；歌单请填用户自有或公开可商用的音频直链。
